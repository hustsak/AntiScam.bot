### `> 01 // OVERVIEW`

**AntiScam.bot** is a cybersecurity project focused on identifying potential online scams, analyzing suspicious files, investigating URLs and IP addresses, and delivering security alerts through Telegram.

### `> 02 // CORE CAPABILITIES`

| Module | Description |
|---|---|
| Malware Analysis | YARA rules and ClamAV scanning |
| URL Intelligence | Suspicious URL and domain analysis |
| IP Investigation | IP address and threat indicator analysis |
| File Fingerprinting | SHA-256 file identification |
| Risk Assessment | Evidence-based risk classification |
| Telegram Integration | Automated scanning results and alerts |
| Machine Learning | Planned data-driven scam classification |

### `> 03 // TECHNOLOGY STACK`

`Python` · `FastAPI` · `YARA` · `ClamAV` · `SHA-256` · `Telegram Bot API`
