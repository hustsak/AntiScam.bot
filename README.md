\### `> SYSTEM OVERVIEW`



AntiScam.bot is a cybersecurity project focused on detecting potential scams, analyzing suspicious files and URLs, investigating IP addresses, and delivering security alerts through Telegram.



\### `> CORE MODULES`



\- \*\*Malware Analysis\*\* — YARA, ClamAV, and SHA-256 file fingerprinting.

\- \*\*URL Intelligence\*\* — Analyze suspicious URLs and domains.

\- \*\*IP Investigation\*\* — Inspect IP addresses and relevant threat indicators.

\- \*\*Risk Assessment\*\* — Combine detection signals into understandable risk levels.

\- \*\*Telegram Integration\*\* — Deliver scanning results and security alerts.

\- \*\*Machine Learning\*\* — Planned extension for data-driven scam classification.
